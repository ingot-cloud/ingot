# 批量导入导出

新增或修改任何业务对象的批量导入、批量导出、模板下载时遵循本篇。参考实现是成员表格：`MemberWorkbookService`、`MemberWorkbookExcel`、`MemberWorkbookPaths`、`ingot-commons` 的 `MemberWorkbook*` 常量与模型。下载中心契约见 [download-center](../../../../specs/current/framework/download-center/SPEC.md)。

## 1. 接口形状

挂在资源命令路径下的独立子路径，不复用、不改动已有 JSON 导出：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/{resource}/workbook/template` | 空白创建模板，同步返回 |
| POST | `/{resource}/workbook/export` | 登记导出，返回下载中心任务 ID |
| POST | `/{resource}/workbook/import` | `multipart file` + `mode`，返回导入任务 ID |
| GET | `/{resource}/workbook/{id}/status` | 导入任务状态与计数 |
| GET | `/{resource}/workbook/{id}/file?artifact=` | 导入产物（错误报告、一次性文件） |
| GET | `/{resource}/workbook/history` | 当前操作者最近 N 条导入 |

- 模式、产物、任务种类都是业务枚举（`CREATE`/`UPDATE`、`WORKBOOK`/`ERRORS`/`PASSWORDS`），按 [enum](enum.md) 形态，`@RequestParam` 默认值用枚举上的 `VALUE_*` 常量。
- 创建/更新两种导入共用一个 import 接口，用 `mode` 区分；权限按 mode 分别校验。

## 2. 导出

- **必须接入下载中心**：在同一事务内校验资源版本（`expectedVersion`），调用 `DownloadCenter.submit`，写审计，返回 `CreatedResource(downloadId, version)`。不新建表存导出文件，不让前端轮询导出状态。
- 新导出来源需要：在 `XxxDownloadSources` 声明 `source` 编码与标题常量；实现 `DownloadSourceAccess`，在签发下载链接前复核导出权限。
- `DownloadJob` 在工作线程里**重新校验导出权限**并按当时的字段可见性投影；授权或身份失效抛 `DownloadJobException`，原因写成用户能看懂的一句话（如「没有成员导出权限，请确认权限后重新导出」），其余业务失败给通用「xx 导出失败，请重新导出」。
- 范围：请求体给「空表示全部可见对象」的语义。按组织范围导出（部门及其下级）由**服务端展开**：请求携带范围 ID，在工作线程按关联查询分页收集。不要求前端逐页拉成员拼 `memberIds`（成员导出当前由前端展开是历史做法，新功能不要照抄）。
- 服务端遍历快照时可以按 `IamPages.MAX_SIZE` 分页循环，这是任务内部遍历，不是对外接口的「大页码取全量」。已移出、不可见对象在投影时排除。

## 3. 模板与工作簿格式

- 列名、分隔符、文件名、sheet 名、Content-Type、脱敏标记全部是命名常量（参考 `MemberWorkbookColumns`），解析和生成共用同一组常量。
- 表头前写「填写须知」行：表头不可改、必填项、多值分隔规则、清空语义、脱敏值不能写回、行数上限与格式。解析时按标志列（如「姓名」）定位表头，允许须知行存在。
- 模板列跟字段可见性走：`HIDDEN` 字段不出列；更新导出比创建模板多一列稳定主键（如「成员 ID」）。脱敏值原样带星号导出。
- 层级引用（部门等）用从根开始的名称路径，层级分隔 `/`，多值分隔英文 `,`，第一项为主值。按当前可读范围建索引解析；不存在或同名歧义该行失败，**不自动创建**被引用对象。
- 单元格归一化：去首尾空白；Excel 把数字读成 `13800000000.0` 或科学计数法时还原成原文本。

## 4. 导入

1. **同步预检**（失败整份拒绝，不登记任务）：必须是 `.xlsx`、非空、能解析、能找到表头、数据行不超过上限（命名常量，成员为 `1000`）。
2. **登记**：事务内写任务行 `PENDING`、记录资源版本、写审计；事务提交后再交给执行器。
3. **执行器**：选应用 `TaskExecutor`（排除 `TaskScheduler`），外包 `DelegatingSecurityContextExecutor`，否则工作线程拿不到身份，所有行会以身份无效失败。`markRunning` 用 CAS，非 `PENDING` 直接返回。
4. **逐行独立**：每行走已有的单条业务入口（如入职 `TenantMemberOnboarding.create`、资料补丁、任职替换），复用其权限、范围、字段策略与版本校验，不旁路写库。一行抛 `BizException` 只记 `(Excel 行号, 原因)`，不回滚其他行。
5. **结果**：有可解析的数据就标 `SUCCEEDED`，结果 JSON 只存成功数、失败数和失败明细；整份无法处理才 `FAILED`，失败码区分身份失效与处理失败。

更新导入的语义必须在须知和设计里写清，并按列是否**出现在表头**判断是否写该字段：

- 列不存在：不改该字段。
- 列存在且为空：必填字段（姓名、手机号）该行失败；可选字段（邮箱）清空；多值关系（部门）清空。
- 单元格含脱敏标记：该行失败，原因「脱敏值不能写回」。
- 对象不存在、不可访问、已移出：该行失败。特殊对象的受保护属性（如组织拥有者的任职）发生变化时该行失败。
- 更新导入不改账号状态、不重置密码。

## 5. 导入产物与保留

- 产物：原始工作簿、错误报告（「行号」「原因」两列）、创建时产生的一次性敏感文件（如初始密码）。
- 敏感文件**只能下载一次**：首次读取原子地取出并清空，再次请求返回 `OBJECT_NOT_FOUND`；状态接口用布尔值告诉前端是否还能下载；历史与结果 JSON 里不出现明文。
- 任务只对发起人可见，按 `(tenant, actor, id)` 查询，他人返回 404。进行中下载产物返回 503 类，失败/过期返回 404。
- 任务保留期、历史条数是命名常量（成员为 24 小时、10 条）；读写任务前顺手把到期任务标 `EXPIRED`。
- 成员导入目前把文件存为 `MEDIUMBLOB`。新导入如果文件可能较大，优先把原始文件和错误报告放 OSS（库内存 `bucket/objectName`），不要再加 BLOB 列。

## 6. 测试

- 模板与导出：隐藏列省略、脱敏值带星号、已移出排除、范围求交、工作线程重新鉴权。
- 解析：表头定位、行上限、非 xlsx、数字归一化、层级路径唯一/歧义/未知/多值顺序。
- 导入：创建/已有/重新加入、更新清空语义、受保护属性失败、脱敏写回失败、部分失败计数、清空安全上下文后工作线程仍能完成。
- 产物：敏感文件只能取一次，他人任务 404。
