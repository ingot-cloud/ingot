# 公共字段访问控制规则

## 资源与字段身份

资源以 `ResourceKey(domain, applicationCode, resourceCode)` 唯一标识。字段键是资源内稳定逻辑键，资源目录集中配置展示名、支持的可见性、编辑/筛选上限和脱敏规则；实际 Java 属性、JSON 别名以及多个接口 DTO 可以映射到同一逻辑键。

`FieldCapability` 包含 `key/label/visibilities/editable/filterable/mask`，不包含排序权限。能力目录是配置上限，不直接授予访问权限。未绑定字段允许保存，但有效能力由目录和后端实际接入清单取交集，未接入能力不可授权生效。

平台角色版本分别保存 `ResourceFieldDefinition.visibility` 和 `operations`，缺失字段为 HIDDEN，缺失操作能力为 false。发布新版本不自动改写已有角色分配；字段新增也不自动扩大历史角色权限。

## 注解与执行职责

无执行依赖的模型及 `FieldBinding`、`PublicField`、`FieldControl` 注解位于 `ingot-commons`；执行逻辑位于 `ingot-access-control`。公共引擎不依赖成员字段枚举。

`FieldBinding` 绑定逻辑字段与 READ/WRITE/FILTER 用途，资源可以显式声明或继承可信接口上下文。`PublicField` 标记固定公开属性。`FieldControl` 声明实际接口资源、精确操作及受控类型。启动时编译不可变注册表和操作清单；未分类属性、冲突、重复输入绑定、受控原始类型及嵌套循环拒绝启动。非文本字段只能 HIDDEN/FULL。

注解负责分类和映射。业务服务仍需执行动作准入、对象范围、读投影、事务内写门禁和查询前筛选门禁；框架不生成业务 SQL。`FieldPolicyProvider` 隔离本地和远程 IAM，`FieldTargetProvider` 批量提供可信对象属性。

## 逐对象可见性

| 可见性 | 后端响应 | 前端交互 |
| --- | --- | --- |
| HIDDEN | JSON 属性省略 | 字段不展示、不可编辑 |
| MASKED | 仅返回脱敏值 | 只读显示掩码；有编辑权限时使用空草稿 |
| FULL | 返回完整值 | 正常展示，按编辑权限进入编辑 |

`FieldAccess(visibility, editable)` 针对实际目标求值，不能独立授予业务动作或对象范围。MASKED 允许编辑；HIDDEN 的 editable 必须为 false。列表、详情、嵌套对象及集合按实际对象投影；不修改原实体、共享实例或 record。导出、RPC、任务可调用直接投影入口；异步调用显式传递不可变上下文。序列化与逐行投影阶段不执行授权 SQL/RPC。

脱敏类型为 PHONE、EMAIL、ALL、KEEP_EDGES、RANGE。规则只适用于文本，参数保存时校验；按 Unicode code point 处理，短值不能因保留头尾而完整泄露，异常格式全遮盖，null 保持空值语义。资源保存规则后审计并失效，请求内保持相同规则版本。不执行自定义脚本或正则。

## 编辑与筛选

全局操作结果为精确 `actionCode → fieldKey → FieldOperations(editable, filterable)`，不依赖当前页面行样本。全局编辑结论与实际目标范围、非 HIDDEN 可见性共同决定行级可编辑状态。

平台可见性按 FULL > MASKED > HIDDEN 合并，操作按精确 action 合并。授予来源各自保留对象范围，不能将一个角色的字段权限与另一角色的对象范围拼接放行。

租户可见性保留查看者和目标范围限制；操作规则独立按资源、场景、查看者和 action 判断，不使用目标范围。匹配规则覆盖默认后仍受平台上限限制，多匹配取交集；业务更新的目标范围继续校验。通讯录不授予成员管理编辑。

写入在同一业务事务中依次加载/锁定真实目标、核对版本与归属、收集实际提交键、调用 `FieldWriteExecutor.require` 重新获取当前授权、执行业务校验和更新。浏览器预览结果不能代替最终写校验。

PATCH 缺键保持原值，显式 null 仅清空业务允许的 nullable 字段；未知键、只读键和未绑定 WRITE 的键拒绝。嵌套单对象递归检查，批量输入按每个实际目标分别授权。前端使用实际输入事件标记 dirty，脱敏字段未触碰不提交，不补取原值。

筛选在 SQL 和 count 前执行：条件必须已接入 FILTER、获准筛选，并能证明整个有效查询范围 FULL。不能以当前页样本放行，也不能静默忽略禁止条件。首轮仅接入现有平台显示名、租户/通讯录手机号邮箱及示例标题条件；固定业务排序不变。

非法参数返回 400，权限不足 403，乐观版本冲突 409，授权或清单依赖不可用 503。

## 清单、上下文与缓存

平台成员上下文和新增的租户成员、通讯录、ops incidents 上下文返回潜在可见列、操作能力和脱敏规则；它们受既有业务准入保护，不能替代逐对象授权。资源字段绑定接口只返回实现清单，不含业务原值。

跨服务清单通过固定 `/inner/iam/field-bindings/manifest` 获取，使用受控服务发现名、专用 HMAC 密钥、固定 purpose、调用服务和完整资源身份。密钥至少 32 字节；不伪造用户身份，不接收浏览器提供的任意 URL。

策略、字段配置及公共默认引用接入 `LayeredCacheBuilder`；编译索引使用 `VersionedDerivedCache(source, version)`。字段授权路径关闭 resilience/local floor，依赖故障不能借 LKG 放行。读授权窗口不超过 30 秒，配置来源携带绝对期限，派生策略与远端决策继承最早期限，叠加缓存不延长窗口。写事务 fresh 读取当前身份、分配、资源上限及租户策略，不可变角色版本索引可复用。

配置、分配和身份关系变更提交后，发布方先清本地缓存再广播；事务回滚不失效。一次请求批量加载角色版本、选择关系和对象部门事实，授权读取次数不随返回行数增长。

启动只编译本节点注解并预热本服务资源及公共默认策略，不全量遍历用户、租户或对象。本地绑定冲突启动失败；远端预热失败记录告警，受控请求拒绝，后续读取可重试。

## 已接入范围与兼容要求

平台/租户成员、通讯录、关联成员响应、导出及 iam-ops 已接入。`joinedAt/lastLoginAt/updatedAt` 为只读受控字段，保持各场景原有返回范围，不凭字段目录扩充载荷或业务输入控件。

当前字段契约直接替换旧字段模型，IAM、SDK 消费服务及前端须同批升级；内部授权仍使用 v2 路径，缓存按新契约版本隔离。新库使用权威 DDL 和初始化生成器；已有库使用独立 [016 迁移脚本](../../../../databases/iam/migrations/016_field_access_control.sql)，重跑 006 不会转换已有记录。

迁移保留身份、角色固定版本引用和分配，不自动授予历史角色新时间字段。无法等价转换的旧租户目标范围编辑规则保守关闭并留档，管理员审核后重新配置。执行前停写、备份和等待缓存到期；回退恢复整批应用及迁移前备份。具体操作约束见 [数据库迁移说明](../../../../databases/iam/migrations/README.md#016-公共字段契约升级)。
