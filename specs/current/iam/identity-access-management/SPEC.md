# 身份与访问管理规则

## 身份与初始化

全局账号负责登录凭证及全局启停/锁定；平台成员、租户成员分别持有当前域资料与资格。同账号可有多个成员身份，单域成员暂停/移出不改变其他成员身份。平台登录建立 PLATFORM、tenantId 为空、allows 为空，不进入组织选择；租户单候选自动进入，多候选先选择。平台管理组织的权限不授予租户业务身份。

正式入口为全新系统初始化，使用 databases/ingot_iam.sql；默认平台账号首次改密后重新登录。新组织仅写组织、拥有者成员、根部门/关系、开通及必要策略事实。当前拥有者由有效成员及 ownerMemberId 动态识别，不写固定拥有者授权分配。已有库脚本另按各自适用版本管理，本能力不提供全量历史迁移、双读或兼容接口。

强制改密账号仅可访问公开入口及精确 GET/PUT /v1/me/password。业务、仅登录接口与 SYSTEM 分支均不能绕过；状态不可取得时拒绝。密码 PUT 使用现有 HYBRID 整包协议，执行现有密码策略。成功后撤销原访问和刷新会话，须重新登录。

## 应用、资源与菜单

ResourceKey 使用管理域、应用编码及资源编码完整键。操作是资源下精确 ACTION，不从菜单、角色名或跨应用同名资源推导权限。默认目录为五个内置应用；扩展应用显式注册。普通租户成员同时受应用启用、开通、人群及操作授权限制，拥有者按现行即时授权规则求值。

菜单只表达导航及条件，不能增加业务权限。OPEN 仍受应用准入限制，ACTION 按 ANY/ALL；隐藏页也须通过权限。路径、路由名、viewPath、隐藏参数和缓存配置分开处理；非法父级或冲突拒绝整笔写入。前端不能以隐藏作为授权旁路。

## 平台角色、分配与委派

普通平台角色发布不可变固定版本；既有分配不因发布而升级。分配绑定主体、固定版本、逐操作范围参数及有效期。预览只读，提交按当前来源、对象、目录、成员/组事实与版本重新校验。多角色、多主体与升级批次失败不部分落库。

治理资格与受限委派独立。受限管理员使用本人一条有效来源，不能拼接来源、再委派或操作无关直接记录；来源固定版本白名单、资源/对象上限、接收人、期限与最长时长持续约束派生授权。组变化不能扩大到既有派生资格之外，冲突扩大原子拒绝。

SYSTEM role_admin 仅可信、有效的平台成员直接分配适用，动态覆盖启用平台操作、ALL 和已注册业务字段 FULL，物理字段能力仍限制写入/筛选。普通治理角色无此特例。不能给组或经委派授予 SYSTEM，普通角色不能占用保留编码。最后一个当前可用、永久有效的超管不能通过撤销、改未来/有限期、停用/移出成员或全局禁用/行政锁定被消除；并发仍保留至少一个。安全自动锁定沿安全框架策略。

租户与共享角色使用完整当前权限及内部快照，分配用 roleId；即时保存、拥有者及资源委派以[租户基线](../tenant-live-authorization/SPEC.md)为准，不恢复租户版本/差异定制流程。

## 范围、字段与成员资料

每个来源先计算同一精确操作及目标范围，再合并来源；不能把全组织只读与某部门编辑拼成全组织编辑。修改校验原归属和新归属；成员任职、部门移动及状态操作分别按现行对象规则校验。动态所属部门随任职变化，明确指定部门不随操作者调岗改变。

平台字段固化在角色版本；同一操作、同一对象的多来源取 FULL > MASKED > HIDDEN，并受目录上限限制。read 的 FULL 不补 update/export 的字段权限。HIDDEN 不返回原值，MASKED 服务端脱敏；显式 null、未知字段和脱敏值回传均不能绕过写门禁。租户资源字段策略按[独立基线](../tenant-field-policy/SPEC.md)执行。平台独立成员/组字段策略已退出。

平台联系 phone/email 与全局账号、同账号租户资料独立；显式清空不回退账号值。创建仅复制初始联系资料一次；MEMBER_CREATE 候选不泄露账号联系方式。loginPhone 是独立公共登录标识，按当前契约返回。成员角色编辑提交差量，未加载页不被隐式撤销；资料与角色变更同事务，保留未改分配的固定版本、主体与期限。

时间点收发带时区 ISO-8601、响应 UTC Z，数据库和判断使用 UTC。有效区间起点包含、终点不包含，MySQL 授权/状态筛选使用微秒精度，计数与明细同规则。字段可见性仍控制只读时间的返回。

## 导出、任务、审计与失败

成员 JSON 导出与 xlsx 工作簿/下载中心分开。异步工作线程恢复可信身份，继续按各链路约定重验当前资格、对象与字段。JSON 交付按当前交集；已生成工作簿保留生成时快照，取件仍校验当前资格及发起人。导入逐行提交和错误报告不改为整文件回滚。

JSON 导出、成员/部门工作簿任务登记与审计同事务；到期清理按候选主键定位并复核，防止并发范围锁死锁。对象删除在提交后执行，失败保留路径供重试；审计失败回滚登记并处理新上传补偿。保留原 24 小时期满、状态竞争、权限和发起人边界。

授权变更提交后失效并广播，广播方清本地；节点装配等待事件总线。读取有绝对截止，写入实时校验；依赖故障返回明确 503，撤权 403、隐藏对象 404、陈旧版本 409，失败不留下部分分配/审计。诊断/候选/预览只读且受披露范围限制，审计记录真实来源及前后事实。

## 能力分工

平台版本应用、租户成员/部门/组/设置、字段策略、平台读取预算、下载中心和同源登录分别沿对应 current 能力；本页描述跨能力边界。普通通讯录与旧 PMS 业务实现退出，必要的安全、Member、MyBatis 范围和下载框架不因主变更被重写。
