# 平台管理读取性能

## 适用接口

请求内授权复用仅用于 `/v1/platform` 下显式标记的十个同步 GET：

| 路径 | 读取内容 |
|---|---|
| `/members` | 平台人员页 |
| `/roles` | 平台角色页 |
| `/roles/{id}/members` | 角色有效成员页 |
| `/assignments` | 分配页 |
| `/delegations` | 委派页 |
| `/roles/{id}` | 角色摘要与能力 |
| `/roles/{id}/grants` | 当前固定版本授权与摘要 |
| `/roles/{id}/revisions` | 历史版本页及差异 |
| `/roles/{roleId}/version-applications` | 版本应用任务页 |
| `/roles/{roleId}/version-applications/distribution` | 可见分配版本分布 |

网关前缀为 `/api/iam`。公共接口、响应字段、分页总数、能力标记、拒绝原因及时间契约不改变。

## 请求内授权来源

MVC interceptor 在方法鉴权之前为标记方法建立请求属性上下文。上下文绑定当前 Authentication 对象及完整 AuthorizationContext；每次访问核对认证和身份，不读取客户端替代身份。请求结束、异常完成或异步移交清理，不向其他请求或工作线程传播。

有效身份、改密状态、普通授权视图及实时授权视图分别保存。普通视图继续使用现有最长 30 秒分层授权缓存；在线注解、展示能力及独立 UPGRADE 资格使用本请求的数据库实时来源，不能由普通视图满足。复用视图必须未到期，到期重新求值；查询异常不保存，基础设施故障仍拒绝。

仅原始 REQUEST dispatch 的同步 GET 可以复用；认证对象或身份变化、实际写事务、其他 HTTP 方法及异步处理均绕过复用。安全过滤器的在线会话、身份和改密门禁保持原样。写命令、后台 worker、授权 RPC、非 HTTP 调用及原始缓存 loader 保留原有实时校验，不新增跨请求授权或进度缓存。

## 列表附属数据

平台人员当前页的更新、状态和移除能力分别编译本操作范围，通过现有 ObjectScopeSql 谓词批量查询允许的成员 ID；最多三条查询，保留 REMOVED 过滤。无操作资格与越出对象范围的拒绝原因不混用，字段投影和租户部门覆盖规则保持不变。实际写入仍独立重验。

历史分页复用已取得的版本行，必要时读取页边界之前最近的版本；本页和边界版本的授权、差异、参数各批量查询一次，按版本及原主键顺序归组，沿用固定基础与差异计算。角色定义校验和摘要能力装配分开，依赖读取不装配随后丢弃的按钮能力，详情和列表仍返回完整能力。当前授权复用最新版本行，普通完整角色只加载所需授权与字段快照，基础版本合成保留原条件。

任务页通过内部业务域端口批量读取目标版本，一条 SQL 按 task_id、status 聚合计数。统计限定当前页任务并应用与明细一致的 assignment_id 可见范围；七种状态缺失补零，空任务页与空范围不查询。单任务计数使用同一聚合逻辑，任务分页总数不因明细统计改写而变化，名称与进度直接读库。

上述附属查询数量不随当前页行数线性增长。分配、委派原有批量关联数据读取、治理与委派边界、任务快照、锁、租约、审计及执行流程不变；无需数据库迁移或前端升级。
