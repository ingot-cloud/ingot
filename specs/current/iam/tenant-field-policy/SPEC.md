# 租户资源字段策略

## 接入与读写

只有服务端声明字段策略运行能力、归属租户域且配置了字段的资源允许启用接入。平台资源目录通过 `fieldPolicy` 管理接入状态。租户成员默认接入，平台成员按角色字段快照求值。

`GET /v1/tenant/policies/field-resources` 列出当前租户可配置资源、字段能力和动作。通过 `GET /v1/tenant/policies/fields/{resourceId}` 读取策略，通过同路径 PUT 携带 `expectedVersion` 保存。读取和保存分别要求 `iam-tenant:field-policy:read` 与 `iam-tenant:field-policy:update`。字段、动作和规则必须属于路径资源且在资源能力内。

## 求值

每个 `(tenant_id, resource_id)` 策略钉住同资源默认修订，字段缺项回落到资源自身默认值和能力。读取已接入但尚无策略行的资源时补建策略；缺少默认修订时由资源默认值生成首版。成员默认完整显示姓名和头像，手机号、邮箱脱敏。

未接入资源只走角色快照。已接入资源先按租户规则收紧，再与有效角色字段权限并集取更严。空角色快照不额外收紧。组织拥有者跳过租户规则与角色交集，仍受平台默认修订和资源能力限制。筛选要求整个查询范围内字段均可完整查看。

## 结构与兼容

策略、规则与默认修订按资源归属，字段策略接口不带场景。普通通讯录浏览、通讯录可见范围及策略预览已退出。成员、部门管理和成员工作簿继续使用现有组织管理入口。

新库使用权威 DDL 和种子。仍含通讯录对象或场景列的已有库分别按适用条件执行 `033` 和 `034`，由 `034` 保留原成员策略并归到租户成员资源。见 [IAM 增量迁移](../../../../databases/iam/migrations/README.md)。
