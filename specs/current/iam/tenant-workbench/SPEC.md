# 租户工作台统计

`GET /v1/tenant/workbench/statistics` 要求当前租户会话和独立的 `iam-tenant:workbench:read`。菜单使用同一操作准入。接口无查询参数，返回组织 ID、名称及可选头像签名地址。

- 成员统计覆盖可读范围内未移出成员，含暂停成员。部门统计覆盖可读范围内的非根部门。多部门成员只计一次。
- 用户组统计沿用组列表的租户读取规则。成员、部门、用户组缺少对应读取资格时省略该指标，合法空范围返回零。
- 应用统计对当前可用且存在可见非隐藏页面的应用去重，复用 bootstrap 的开通、人群和菜单授权。依赖或查询失败按既有错误处理。

`org.iam.workspace` 根目录排序为 0，位于组织管理、权限与应用、安全与合规之前。已有库可使用 `035_tenant_workbench_first.sql` 定向更新排序。
