# 租户用户组有效成员

`GET /v1/tenant/groups/{id}/members` 只返回直接绑定。工作区通过 `GET /v1/tenant/groups/{id}/effective-members` 读取直接绑定与部门任职展开后的去重分页。部门规则按 `includeDescendants` 决定是否纳入子部门，任职变化在后续查询生效。

查询要求用户组读取资格与组对象可见，成员按成员读取范围和字段策略投影。当前页附带直接绑定标记及命中的部门来源。部门名称按读取资格披露，来源可以只显示为部门范围。相同成员即使同时直接绑定和命中多个部门，列表也只返回一行。

有效成员口径不另行排除停用账号或已移出成员。全范围查看时分页总数与用户组可见成员计数一致。

组列表、总数、详情和工作台组计数按当前组织及对应组读取范围计算。组预览和更新省略 `selection` 时保留关联，显式传入时按完整替换复核组对象范围和成员资格。

`GET /v1/tenant/groups?view=SUMMARY` 沿用组列表的筛选、排序、分页和总数，只返回组 ID、名称、描述、版本及操作能力。摘要页最多两条列表查询，成员关系由选中组的有效成员接口独立分页读取。默认完整视图按本页组批量读取关联，人数按直接绑定与部门来源去重。
