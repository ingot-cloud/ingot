# 发布与验证设计

使用 [迁移手册](../20261014-iam-tenant-live-authorization/MIGRATION.md) 的已有脚本和检查点。先确认实际环境及执行权限，再做只读导出与预检。按来源结构决定 021 的适用性，完成数据转换与 verify 后安装 022 约束。由发布负责人确定停写和观察窗口，按手册核对所有授权消费节点与管理台版本。

放行前检查数据库一致性、应用与字段授权、平台固定版本、旧缓存和故障分支。观察窗口内按 P09 恢复完整旧备份和旧制品；开放新写入后按 P10 逆转换保留新数据。结果登记脱敏摘要、阶段、检查点及处置记录。

实际窗口安排及操作授权由发布负责人确认。既有隔离证据留在原产品归档。
