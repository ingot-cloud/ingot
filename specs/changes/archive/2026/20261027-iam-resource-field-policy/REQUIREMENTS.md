# Requirements

## 用户场景

平台管理员在应用目录中看到服务器允许的资源接入开关。打开后，租户管理员在字段策略中选择该资源，并按其字段能力配置可见性、编辑和筛选。

租户成员继续使用现有默认：显示名和头像完整，手机号和邮箱脱敏。一个人的多个角色字段权限取并集作为上限，租户策略只能再收紧。组织拥有者跳过租户规则和角色交集，仍受资源能力与平台上限约束。

## 业务规则

- 只有服务器声明具备字段策略运行能力、属于租户域、且已配置字段的资源，目录才能打开接入开关。
- 本次只有租户成员具备运行能力并默认接入。平台成员有字段但不接入，继续只走角色快照。
- 未接入资源不读取租户字段策略。
- 已接入资源：先按该资源的租户策略求值，非拥有者再与角色字段并集取更严。空角色快照不额外收紧。
- 无匹配规则时使用该资源已钉住的默认修订；修订缺键时回落到该资源自己的字段默认值和能力上限。
- 规则中的字段、可见性、编辑和筛选不得超出该资源的字段能力。操作规则的动作必须属于该资源。
- 目标范围仍是全部、本人、所在部门、管理部门、指定对象。
- 多条可见性规则取更严；多条操作规则取逻辑与，再与操作上限和资源能力取逻辑与。
- 字段可筛选还要求该字段在整个查询范围内都是完整可见。
- 新租户为每个已接入且已有默认修订的资源插入策略行。已有租户第一次读取新接入资源时补行，并钉住该资源最新修订。资源尚无修订时，用字段默认值生成第 1 版。

## 边界与非目标

- 记录本身不是成员的资源，本次不能标记为具备运行能力。
- 不新增第二份业务字段，不改变成员列表、详情、导入导出、部门负责人和审计姓名的调用方，它们继续传入租户成员资源。
- 不改写迁移 007–033。新库改 004 与种子，已有库用 034 回填租户成员。
- 动作码 `iam-tenant:field-policy:read` 与 `iam-tenant:field-policy:update` 保持不变。

## 验收标准

- [ ] 成员手机号、邮箱默认仍为脱敏，显示名和头像默认仍为完整
- [ ] 角色字段并集是上限，租户策略不能放宽；拥有者仍跳过租户规则与角色交集
- [ ] 未接入资源不读租户字段策略
- [ ] 平台不能给未声明运行能力的资源打开接入开关
- [ ] 一条字段规则只作用于所属资源
- [ ] 已有库执行 034 后，原成员策略归到租户成员资源，场景列消失
