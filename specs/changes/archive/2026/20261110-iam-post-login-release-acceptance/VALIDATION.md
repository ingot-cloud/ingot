## 2026-11-10 第二轮

### 租户角色分配

租户真实会话在页面验证首页、每页 20 条的第 5,000 页，以及按角色名称搜索。页面总数分别为 100,000、100,000 和 100，均展示本页 20 条。BFF 耗时来自浏览器资源计时的单次请求。MySQL 耗时来自按同一筛选条件分别执行的 `EXPLAIN ANALYZE`，不与 BFF 单次读数相加。

| 场景 | BFF 请求 | MySQL 计数 | MySQL 取页 |
|---|---:|---:|---:|
| 首页 | 176.1 ms | 26.7 ms | 0.37 ms |
| 第 4,000 页 | 仅核对 SQL | 21.9 ms | 17.8 ms |
| 第 5,000 页 | 166.5 ms | 20.2 ms | 21.3 ms |

### 分层缓存与清理

当前 IAM 的 `/actuator/metrics` 无授权缓存分层命中和未命中计数，`/actuator/layeredcache` 未暴露。缓存实现也未启用 Caffeine 命中统计，Redis 实例命中率无法归因于本应用的授权 L2。未记录无法复现的分层百分比。

采样结束后按 ID 范围、角色编码及组标记清理，实际删除 100,000 条分配、平台和租户组各 20 个及其关系、2 个角色和 2 个空权限快照。复查临时记录为 0，原有平台分配保留，`037` 索引仍为 8 列。同比页面和缓存验收未达到结案条件，保留本 change 为 `validating`。

### 平台授权 L1/L2 分层现场复测

2026-11-10 11:45:49–11:45:54（北京时间），复用真实平台 BFF 会话，在 4.807 秒内串行请求用户组摘要首页 51 次，全部返回 HTTP 200。采样前等待授权缓存自然过期，确认 Redis DB 0 的平台授权前缀无匹配键。临时探针仅统计 `iam-authorization` 接受缓存值、穿透下一层和调用加载器的事件，采样窗之外未观测到其他同名缓存事件。

| 场景 | L1 命中/未命中 | L2 命中/未命中 | 回源 |
|---|---:|---:|---:|
| 第 1 次，自然冷读 | 0 / 1 | 0 / 1 | 1 |
| 第 2–11 次，L1 热读 | 10 / 0 | 0 / 0 | 0 |
| 第 12 次，测试探针只使本次请求对应的 L1 条目失效 | 0 / 1 | 1 / 0 | 0 |
| 第 13–51 次，L2 回填后继续读 | 39 / 0 | 0 / 0 | 0 |
| 合计 | 49 / 2（96.08%） | 1 / 1（50.00%，仅 2 次实际访问） | 1 |

本轮通过缓存路径验收。表中百分比属于受控样本，L2 样本分别来自一次自然冷读和一次受控失效，不能外推为长期命中率。未修改 Redis 数据或配置；Redis 填充由业务请求正常完成。采样后撤除探针并确认三处字节码恢复，真实 BFF 复核请求再次返回 HTTP 200。

旧版 `f7feb1fb` 与新版 `d40d3dff` 的后端 `bootJar` 均已在隔离目录离线构建。旧版 `dd3ec45` 与新版 `9682655` 的两端前端产物也已构建，均附同一份浏览器采样页。两版锁文件和包定义相同，复用本机已安装的依赖。实际 P95 对照等待本机可切换运行版本的窗口。
