# 需求与验收

1. PolicyWriteRepository 不再位于 application，名称覆盖真实字段策略读写职责。
2. Query 类型不承载创建、更新、关系替换或 FOR UPDATE；Facade 只编排与委托，不迁入 SQL 或业务规则。
3. 成员创建/资料更新/角色保存的事务、锁顺序、字段校验、审计与投影保持；不新增读取权限要求。
4. 目录与字段策略按现有职责拆分，不改变 SQL 条件、缓存键/载荷、fresh 读取、所有者上限或失败关闭。
5. 同步消费者、Spring 构造装配、测试夹具与门禁；对外 HTTP/RPC/JSON 契约不变。
6. 各阶段定向测试通过后执行完整 IAM、SQL 防护与隔离 MySQL/HTTP 回归。新建库单文件、默认账号和强制改密先核对现有实现，不连接或修改业务数据库。

验收：架构/契约检查、组件扫描和构造无环、定向及完整回归通过；未覆盖的实际环境证据单列；不将代码提交或测试通过标作用户验收完成。
