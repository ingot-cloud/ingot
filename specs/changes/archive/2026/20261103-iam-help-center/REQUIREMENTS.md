# 需求：内置帮助中心

## 场景

1. 当前有效租户成员点击顶栏“帮助中心”，查找添加成员、部门、角色授权、导入导出等使用方法。
2. 当前有效平台成员阅读租户治理、应用配置、平台人员、安全策略及开发配置等说明。
3. 用户从业务页“使用说明”进入相关教程，看截图完成操作；通过文章中“前往功能”进入自己有权访问的页面。
4. 研发修改功能时同步维护正文与配图，经代码评审后同批发布；回滚时恢复相应文档。
5. 租户用户搜索平台词汇、输入平台文章 ID、请求平台图片或伪造域参数时，得不到平台内容。

## 必须满足的规则

| ID | 规则 |
| --- | --- |
| B01 | 只接受服务端可信当前身份；有效成员、管理域、强制改密及现有登录限制继续生效。帮助阅读不新增 IAM 操作码或角色分配。 |
| B02 | TENANT 内容集为 common＋tenant；PLATFORM 为 common＋platform。平台上下文也不直接读取租户专属内容。通用内容禁止包含任一端专属截图或内部信息。 |
| B03 | 同域所有有效成员可读该域帮助；操作所需角色/权限在文章标注。说明阅读资格不授予业务操作、数据或应用开通资格。 |
| B04 | 目录、首页编排、搜索命中及总数、摘要、章节、相关/前后文章、正文、原图和缩略图必须先限定域；禁止先全局命中再删结果。 |
| B05 | 已知其他域 ID 与不存在 ID 在本域均返回统一 404；调用另一域端点返回 403；未认证 401。所有失败不透露另一域标题、路径或资产名称。 |
| B06 | 文档和搜索索引保存在服务端受保护资源中；不得放入前端 public、JS、source map、静态文档站、公开 OSS/CDN 或无需认证的下载地址。 |
| B07 | 用户可搜标题、关键词、章节及正文；中文操作用语由维护者补关键词，同域排序稳定、分页真实，关键词以纯文本高亮。 |
| B08 | 研发用 Git 维护文档，每项实际交付功能及关键非菜单流程有说明，文档、功能映射及截图同步验收。禁止 TODO 正文、空文章或假截图通过发布检查。 |
| B09 | 文章有稳定 ID、分类、适用对象、前提、入口、步骤、结果、常见问题、更新时间；需要定位入口、多步骤填写或解释复杂关系时必须配图。 |
| B10 | 配图使用本系统真实演示界面；图注、编号与正文对应。概念图可用经校验的图稿导出；不使用飞书截图替代本系统操作截图。图片也按当前域与版本校验。 |
| B11 | 文章与截图绑定同一内容版本，滚动发布不拼接不同版本。文档不可用返回明确错误，不转用别的域、旧索引或公网文档。 |
| B12 | 所有对外时间点使用 UTC Z 的 ISO-8601；复用框架枚举、常量、构造注入与 JavaDoc 门禁。 |

## 前后端共同产品要求

帮助界面参照飞书：浅色渐变搜索区、入门卡片、分类入口；文章页为左分类树、中正文、右章节大纲，浅蓝选中态与清晰排版。具备分类收展、目录定位、纯文本搜索高亮、章节跳转/滚动高亮、列表返回恢复、图片放大缩放及 Esc 关闭。项目品牌、明暗主题、窄屏与键盘可达性保留。详细视觉目标由配套前端 `UX.md` 定义。

## 边界与兼容

- 内容面向系统使用者，不直接发布 `specs/`、运维密钥、内部接口或客户业务数据。
- 内容源固定简体中文，本期无语言切换、历史版本浏览、在线热更新及编辑接口。
- 不新增数据库表、业务授权资源或缓存配置。内容来自本地不可变构建资源，不属于远端参考数据分层缓存场景；若未来改为远端加载，另行设计统一分层缓存接入。
- 不修改现有业务操作语义、登录策略及其他 active change 的验收结论。工作台帮助卡片与全局菜单搜索融合不在首期；保留顶栏与业务页说明入口。

## 验收标准

- [ ] BA01：两域全部契约响应通过校验，`R.code=S0200`，参数校验、分页、章节链接和 UTC 时间正确。
- [ ] BA02：双向跨域、同账号双端、匿名/失效/暂停身份、强制改密、伪造 domain/tenantId/appId、猜测 ID 及路径穿越均无泄露。
- [ ] BA03：搜索目录、摘要、总数、相关推荐和前后文章只来自本域；撤销身份后正文与图片接口同样拒绝。
- [ ] BA04：原图、缩略图与资源获取均需认证；前端静态包、source map、反代静态路径和缓存响应中无平台文档泄露。
- [ ] BA05：内容构建拒绝断链、错误章节、跨域引用、外部图片、非法资源、重复 ID、无时区更新时间、空文章与缺少必需配图。
- [ ] BA06：当前发布功能覆盖率 100%；所有 DOCUMENTED 条目有核实正文、必要配图和实操证据；未交付功能单列 NOT_SHIPPED 原因，不能借此排除已交付功能。
- [ ] BA07：版本切换触发约定的 409 恢复，正文/图片不混版；内容失败有明确 503，兼容发布和回滚演练通过。
- [ ] BA08：与前端共同验证飞书式页面、交互、真实截图、业务跳转授权、主题/窄屏/键盘操作及身份切换清理。
- [ ] BA09：验收证据记录后更新 current 并归档；本次生成规格不勾选实施或验收项。
