# 需求

- 全范围查看成员所属组时正常返回，生成SQL通过当前Druid MySQL Wall防护。
- 受限组范围继续以绑定参数筛选；空范围返回空页，不扩大可见性。
- 直接加入、部门加入及连带下级保持去重口径；列表和计数仍按同一成员、可信租户及组范围过滤。
- 分页、排序、响应字段和现有成员/组读取资格保持。无需数据库迁移。

验收：真实Mapper动态SQL的全范围/受限范围通过Druid检查；验证恒真条件仍会被防护拒绝；成员所属组分页、去重、部门继承、空范围和租户隔离回归通过。
