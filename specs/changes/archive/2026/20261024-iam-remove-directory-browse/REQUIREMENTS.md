# 需求：收掉租户普通通讯录

## 场景

租户工作台不再提供普通通讯录。成员查找和资料维护只走组织管理里的成员页。安全与合规里的成员访问策略只配置后台管理字段权限。

## 业务规则

- 普通通讯录成员、部门、字段上下文接口退出。
- 通讯录可见范围的读取、保存和预览退出。预览只说明通讯录里能看到谁，不另做管理端字段预览。
- 字段策略只接受场景 MANAGEMENT。DIRECTORY 规则不再保存，也不再参与求值。
- 角色权限目录不再出现「查看通讯录」、通讯录可见范围策略和策略预览。
- 拥有者动态全权限不再包含已删除动作。
- 成员列表、详情、导入导出仍按 MANAGEMENT 字段策略投影。角色字段快照仍是成员资源的上限。

## 非目标

- 不改成员手机号、邮箱的存储语义。
- 不改成员工作簿导出文件名。
- 不改组织管理部门树和选人用途 `MANAGED_DEPARTMENT`。

## 验收

- 上述接口不再注册。
- 新库种子和已有库迁移后，没有通讯录菜单、相关动作、通讯录策略表和 DIRECTORY 默认版本。
- 字段策略保存只接受 MANAGEMENT，并继续约束成员读取与编辑。
