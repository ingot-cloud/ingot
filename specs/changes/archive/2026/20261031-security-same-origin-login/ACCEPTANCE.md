> 状态：completed；本地自动化与用户功能确认见 VALIDATION.md；目标环境未覆盖项目已移交发布验收。
> 自动化以隔离 Redis/Auth 与可控时钟为主，浏览器与部署证据单独留存。禁止用 Mock 完成勾选真实登录和 TLS 验收。

| ID | 场景 / 方法 | 必须观察的结果 |
|---|---|---|
| A01 | 双域名，两个宿主直接访问 /login/ | 无 tx 可填表；无管理页往返；未认证不拉业务 bootstrap |
| A02 | 纯 IP HTTPS 8443/9443，真实浏览器 | 无 DNS 可登录两应用；Cookie 名独立；只消费当前 app Cookie；Host/端口正确 |
| A03 | 页面停留一小时、隔天、休眠/后台恢复 | 打开时不建事务；点击时准备新流程，输入不因准备重载，旧事务不被心跳续期 |
| A04 | 旧 /oauth2/challenge?tx、/auth/start、/auth/complete?ticket | 本域规范化 /login/ 并清旧参数；不兑换旧 ticket、不跨域、不循环跳转 |
| A05 | 平台账号无租户资格，租户零/单/多候选 | 平台不披露租户；零候选准确失败；单候选完整校验；多候选留本页选择 |
| A06 | 候选在选择前被移除/暂停、错误 tenantId、平台调用 select、Auth有效期缺失/已过期 | 重新校验并拒绝；BFF不猜期限，缺字段503，明确过期410；不能签发不合法租户身份 |
| A07 | 错误密码、账号锁定/禁用、重建事务 | 准确业务文案；失败计数和锁定不因新事务重置；不跨应用降级 |
| A08 | 412、取消滑块、挑战关闭/重试、长时间拖动 | 沿用策略，不预弹；新 HYBRID nonce/时间戳；过期恢复有界，不白做循环挑战 |
| A09 | 绑定/CSRF过期，伪造 CSRF | 未认证准备最多原地修复一次；陌生绑定不能认领旧事务；已认证结果不重新绑定 |
| A10 | 相同 origin 开两个/多个标签页创建事务 | 有效绑定复用；不互相轮换作废；各自状态独立；容量超限明确 429 |
| A11 | 同事务并发 login/select、租约过期和迟到工作者 | 同阶段 Auth 只执行一次；栅栏拒绝旧执行；不能产生两份正式结果 |
| A12 | 登录/选择响应丢失、旧会话仍有效 | GET准确核对本事务；旧账号会话不能证明新登录成功；合法 resume 同 session，无重复换码 |
| A13 | 恢复窗口过期，退出/禁用/踢出后 resume | 明确拒绝，不复活已撤销身份；远端不可用时 503，不假在线 |
| A14 | 同应用不同账号事务先后成功、旧响应迟到 | 代次阻止旧身份重新激活；旧 UI与查询清理，不能把迟到 Cookie 当新会话 |
| A15 | 平台与租户同时在线，分别退出/切换 | 不覆盖另一 Cookie、不误读身份、不撤另一 app sid；全局账号安全撤销仍生效 |
| A16 | 别浏览器/别应用重放 tx、篡改 URL/appId/domain | 403/400并无候选/Token泄漏，不能用 result/resume获得他人身份 |
| A17 | 非法 Origin、null/缺 Origin写请求、伪造 In-Inner-* / X-Forwarded-Host | 同源/可信代理检查拒绝；无 CORS 绕过，普通表单不触发认证 |
| A18 | 新正式会话及存储检查 | sessionId与匿名binding不同；前端无Token/PKCE/Auth Cookie；日志无完整敏感值 |
| A19 | Auth 超时/5xx，Redis故障，提交后响应丢失 | 503与过期区分；提交前故障保留旧态；已提交按结果恢复，无伪成功/盲重放 |
| A20 | 未提交sid、未交付结果、已交付结果过期及撤销故障 | 清理幂等、可重试、有告警；不只删键；已交付活跃身份不被结果TTL误撤 |
| A21 | 初始密码/重置密码、强制改密、权限为空/域不符 | 继续受限改密；不先装配业务；无菜单正常空态，域不符阻断不循环登录 |
| A22 | 非根深链、手动收藏登录页、显式退出/切换账号 | 只恢复同源规范化相对深链；显式退出进入表单，不被残留 me 弹回旧页面 |
| A23 | TLS/SAN/CA、反代与静态资源深链、未知 Host | 可信 HTTPS可用；错误证书/未知入口失败；API不回HTML；无localhost生产回跳 |
| A24 | 协调发布、旧Cookie/Redis清理、回滚演练 | 无新旧协议混跑；只清本内部客户端；一次重登；完整回滚后旧环境可用 |

## 自动化证据

- BFF 状态机、TTL、来源/CSRF/绑定、容量、每种错误映射和恢复条件。
- Gateway Host/port/appId、Cookie 选择、代次/sid、匿名路径不继承 Bearer。
- Redis 并发/租约/栅栏、原子提交、结果交付确认、清理重试；含实际部署使用的 Cluster 同槽校验。
- 前端点击链路、全局挑战、无 tx 初始化、身份纪元、响应丢失、明确退出及受限改密。
- 定向契约快照、类型/Lint/构建。不是为静态文档运行全仓测试。

## 浏览器与运维证据

平台、租户各至少一名非超管和一名受限/需改密账号；多组织账号及另一浏览器。
双域名与纯 IP 双端口分别记录地址、证书信任、请求链、Cookie名称/属性、登录/退出/恢复结果。
证据必须脱敏，不截取密码、完整Cookie、Token、CSRF；可记录 code、阶段、时间、脱敏事务关联和断言。
时钟推进的自动化不能替代至少一次真实长停留/休眠浏览器验证。部署切换与回滚由实际维护窗口确认，不自动勾选。
