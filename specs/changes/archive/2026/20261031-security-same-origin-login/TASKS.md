## 1. 本轮明确的决策

| 项 | 决策 |
|---|---|
| D01 部署 | 双应用同源；双域名或纯 IP HTTPS 双端口，无四域兼容 |
| D02 宿主 | 两管理 App 挂载 auth-plugin；不运行独立登录 App |
| D03 事务 | 点击创建；默认 600秒；单绑定多事务，默认最多5个 |
| D04 绑定/CSRF | 有效复用；创建事务至少续至其期限；不升级为正式ID |
| D05 完成 | login/select 直接提交正式Cookie，COMPLETED；删除浏览器ticket/complete |
| D06 不确定结果 | 只读核对+同绑定60秒有界resume；不能仅看me有任意会话 |
| D07 并发 | CAS/租约/栅栏，代次提交，当前代次才可恢复；不能盲重做Auth |
| D08 交付与回收 | 首次正式Cookie使用确认；未交付有界撤销；已交付不随结果TTL撤销 |
| D09 错误 | 业务/过期/依赖故障分类；403不全局跳转；503不撤旧身份 |
| D10 Cookie | 按应用命名，host-only；IP不按端口隔离，服务端严格选取 |
| D11 兼容发布 | 协同破坏性切换、v2 Redis、一次重登、完整环境回滚 |
| D12 代码门禁 | Java枚举/时间/常量/JavaDoc/构造注入及前端分层均沿用仓库规则 |

没有“实施时再选同源还是四域/是否保留ticket”的开放决策。恢复/提交细化已随完整 Spec 获用户确认；后续偏离仍按 SDD 重新对齐。
