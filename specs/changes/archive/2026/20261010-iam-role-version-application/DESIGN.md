# 已批准设计

版本表增version_name、remark、metadata_version；名称不参与身份，历史及缺省显示vN；系统只读。创建/发布/租户基础升级输入支持名称备注，发布可指定同角色sourceRevisionId并继承其共享基础。元数据PATCH使用独立乐观锁、既有角色更新资格（STATUS操作）及审计，不改变权限或分配；展示查询直接读取数据库，不存在需要清除的独立版本展示缓存。

新平台应用计划及明细表保存可信发起身份、目标、快照与原分配版本/范围、覆盖值、状态/错误/进度，不保存令牌。新API提供发布并准备、准备现有目标、查询及分页项、绑定/明确排除调整、重验、确认。旧升级接口向上且100条限制不变；共用分配校验/复用/写门禁。

快照按角色关联SQL与集合选择建立，不前端拉全量；所有查询和计数服从同一对象边界。必须独立UPGRADE治理资格；目标非系统平台自定义。范围键/类型/资源兼容才复用，新增项需明确选择。复用门禁保留对象、期限、委派来源与范围。

ALL 和来源版本集合必须覆盖集合内全部有效分配的治理范围，不静默遗漏不可治理记录；候选和统计仍仅返回可见范围。指定分配不可见时返回对象不存在。普通读取沿用现有最长30秒缓存，准备/调整/确认和执行批次使用fresh校验。新增分配不补入已建立的快照；未来生效时间保持不变。任务表保留角色外键，存在任务时角色删除返回对象使用中。

PREPARING→READY或BLOCKED→RUNNING→SUCCEEDED；运行故障PAUSED，重验未完成项回READY/BLOCKED。任务按DB租约领取，同角色一个运行任务；租约受事务内fencing保护，批次100条。可信任务身份通过ActiveIdentityService恢复并fresh准入；事务锁顺序沿用授权→角色→分配，批次写入/明细/审计同提交，提交后缓存失效。并发/撤权/故障不跳过，不回滚已提交批次；重复确认不重复执行。

前端复用admin-common范围选择器与独立向导/元数据弹窗；实体候选分页默认20，不裸ID录入、不拉全集。实际权限完整深拷贝。发布与应用分开反馈。只预览任务不产生持久角色草稿。

新增017可重跑增量与权威DDL/种子生成同步；数据库→全部后端→前端。回退先停止运行任务，保留表列和审计，已完成权限通过新任务恢复。实现期间维护任务，不提前current/归档。

消费模块配置 `ingot.iam.role-applications.worker-enabled` 默认true；回退先在全部节点关闭领取并确认当前事务结束，再由运维暂停剩余任务。租约30秒，工作节点每秒尝试领取；数据库生成列唯一索引与事务锁共同保证同角色运行互斥。任务身份只保存账号/成员标识，通过当前有效身份恢复，不持有登录令牌。

宪章符合性：应用编排留插件，共用模型和交互放公共包，主题Token/标准控件，无跨插件依赖。

2026-10-11：初版每秒领取扫描由已批准的 [调度优化](../20261011-iam-role-application-scheduling/DESIGN.md)升级为提交后唤醒、按ID续批和每节点60秒兜底。数据库30秒租约、任务状态、批次门禁和审计语义不变；最终配置及恢复窗口见关联运行说明。
