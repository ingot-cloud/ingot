# 需求与验收

来源：用户明确要求实施本会话最终《角色版本信息与批量应用计划》。

全域非系统角色版本支持名称128字、备注512字及独立元数据乐观锁；权限内容保持不可变。支持基于同角色历史版本编辑，保留字段快照与租户固定共享基础。首轮批量应用仅平台自定义角色，选择全部、来源版本或指定分配，支持高低版本。包括直接/组/未来生效分配，保留主体、期限和委派，不纳入撤销或到期记录。

默认复用兼容范围，逐条或明确批量补齐；预检全部通过才能应用，不自动扩展委派。发布并准备应用同事务保存新版本和计划，冲突保留发布、零分配更新。持久异步任务每批最多100条，租约、同角色互斥、幂等、事务审计、重启接续；冲突/撤权/故障暂停，已成功批次保留，重新预检后确认继续。

前端可读版本名称、备注编辑、历史编辑、发布选项、范围向导、差异和任务记录；区分最新发布版本与分配分布。无持久角色草稿，无跨租户推广，无自动执行目标库/部署/提交。

自动化覆盖元数据并发、历史克隆、范围/字段/委派、100条以上、幂等、租约重启、撤权与并发暂停、迁移/契约/类型/构建；真实主题/窄屏/大集合由负责人jy验收。
