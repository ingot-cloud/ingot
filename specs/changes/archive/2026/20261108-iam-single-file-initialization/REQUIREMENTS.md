# 需求与验收

- 用户只执行一个ingot_iam.sql，无需预建库、选择数据库或另行导入种子。
- 入口固定重建ingot_iam，清除该库原表及数据；最终仅有59张运行表，包含IAM及所依赖框架需要的存储。
- 初始化包含5应用、44资源、181权限操作、41菜单及关联、2个治理角色及版本、默认字段策略、发号起点，以及唯一平台管理员及角色分配；默认密码11111111，must_change_password=TRUE。没有测试租户、普通测试账号、安全事件或迁移记录。
- 7张已核对的历史表及该库其他非运行表随重建清除；其他数据库不受影响。不是已有数据的增量升级方案。
- 历史SQL、运行表DDL和种子内容保持；不连接或修改用户实际库。
- 验收覆盖无库导入、分片/单文件一致、重复重建、历史/额外表清除、其他库保留、外键开启及会话设置恢复、平台账号和权限数据，以及使用交付SQL的隔离MySQL/HTTP回归。
