## 执行入口

在仓库根目录运行以下命令。本地测试库方式要求先创建空的 `ingot_iam_catalog_test`，并使用只对该测试库有权限的账号连接。

```sh
mysql --user=你的测试库账号 --password --database=ingot_iam_catalog_test < databases/ingot_iam.sql
```

[完整初始化 SQL](../../../../../databases/ingot_iam.sql) 会重建目标库内清单中的表。[目录种子](../../../../../databases/iam/006_bootstrap.sql) 已包含在其中，单独执行种子会跳过已存在的记录，无法替换旧编码、菜单绑定和既有角色版本。

只验证目录和最小角色时，以下命令用本机的 `mysql:8.4` 镜像创建临时容器，导入完整初始化 SQL，重建 11 个最小权限角色并检查菜单，结束后移除容器。

```sh
python3 databases/iam/test_bootstrap_seed.py BootstrapSeedTest.test_rebuilt_minimal_roles_open_only_their_authorized_page_entries
```
