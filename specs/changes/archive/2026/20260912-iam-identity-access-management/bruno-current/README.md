# IAM 现行 Bruno 验收

使用已登记的独立环境。先按 [TEST-DATA](../TEST-DATA.md) 创建本次 runId 的基础和平台权限夹具，再为研发只读成员分配研发范围的成员读取与诊断操作。

在 Bruno 打开本目录，选择 `isolated`。填写本次 Gateway 回环地址、runId、组织 ID、读者成员 ID、可见成员 ID、范围外成员 ID、租户应用 ID、成员读取操作 ID 和本人发起的成员导入任务 ID。四个 bearer token 用本地秘密变量填写。它们分别来自平台治理、纯委派、组织拥有者和研发只读会话。

运行 01–06，记录每项状态和业务码。检查包括平台应用显式域、纯委派分配资格、辅助写入拒绝、受限诊断、范围外成员拒绝及产物缺参。只保留脱敏运行结果，令牌和本地环境值留在隔离执行环境。

历史请求见 [原 Bruno 集合](../bruno/README.md)。
