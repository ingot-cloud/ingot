# 授权执行与资源接入规则

## 同源事实与执行

IAM 是业务授权事实来源。当前可信域、成员与完整 ResourceKey 决定精确操作、对象范围及字段结论。AuthorizationAccess、@IamAction、对象 Guard 和 SQL 范围执行分别承担功能准入、目标与两端归属；前端按钮和 JWT 角色文本不能替代实时判断。

MyBatis DataScope 注解、过滤器及既有默认 IN/OR 谓词仍供已接入消费者使用，不把旧 PMS 数据表/角色来源模型带回 IAM。未接入资源不会自动获得行过滤。超大谓词改写独立评估，不由本能力引入闭包表或 UNION。

## SDK 缓存与失败

SDK 配置键归 ingot.iam.authorization；既有 MyBatis 消费键 ingot.mybatis.scope 保留归属。统一分层框架装配 L1、刷新通知、L2 和 loader，不启用授权 LKG/地板。读热窗口最长 30 秒并截断到源端绝对截止，不能在回填时延长期限；关键写必须 fresh。合法空授权与不可用分开，空值不进热缓存。

授权失效协调器在事件总线之后装配。提交方先清本地并广播，远端热节点收到后失效；广播丢失仍受绝对截止。依赖失败使用明确拒绝/503，不由旧 JWT 或过期缓存恢复授权。SDK 将项目 Feign 的已知 IAM reasonCode 保留，未知错误按 unavailable；IAM v2 的稳定状态映射限于现有指定内部授权契约，不改全局旧内部协议。

## 独立对象 RPC

资源登记配置为 ingot.iam.resource-rpc，白名单显式绑定完整资源键、服务名、能力和密钥，不接受浏览器 URL。密钥由可信配置注入。远程请求带原 Bearer/在线成员、内部来源和签名，任一身份/租户替换或缺失均拒绝。POST /inner/iam/resource-objects/query 使用专用在线身份安全链，其他内部接口保持既有边界。

候选、存在性和 SQL 对象来源由业务资源服务实现；合法空 allowedIds 返回空结果，不能扩为全部或误作依赖故障。同名其他应用、同 ID 对象不混合授权。资源服务不可用时保存/升级校验拒绝且不部分写入，恢复后可以在仍有效的原会话重试。

字段清单使用独立服务签名路径，不用成员 token 替代；方法安全代理需能创建。零字段资源的空 defaults 合法，有字段仍须声明安全默认。字段绑定、逐对象投影与物理能力遵循[字段框架](../field-access-control/SPEC.md)。

## 接入与边界

examples/iam-ops 使用标准数据库、在线身份、安全和 SDK 装配，可独立 bootJar。Feign 超时配置按 contextId 定位，服务发现名保持稳定；动态 Feign 接口不因缺少 @FeignClient 元数据失败。

授权到期、撤销、组变化和 IAM/对象服务停止时均按上述规则拒绝。列表、count、详情、导出和修改使用各自精确操作，read 的字段或范围不能补其他操作。生产数据量、查询预算和 P95 应按具体入口测量；本机代表规模结果不声明生产 SLA。
