# 环境验收执行设计

复用归档 change 的 API、DEPLOYMENT 与 ACCEPTANCE，以及两套前端受控浏览器脚本；业务实现不变。每项分别标记本地自动化、用户本地确认、目标环境实测，三者不互相替代。

先确认地址/证书/版本和回滚备份，再在隔离目标环境执行正向与安全/故障场景。生产切换与回滚只在明确的维护窗口和授权内执行。记录只保留脱敏阶段、错误码、请求次数、Cookie属性和补偿结果，不保存密码、Token、Cookie值或sid。

若验收发现实现缺陷，更新本 change 的设计、测试与批准记录后修正；若改变已归档接口/安全边界，重新对齐方案，不能借验收直接改变契约。
