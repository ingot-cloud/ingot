# 剩余环境验收需求

本记录只承接原 A01–A24 中缺少实际环境证据的部分，不重开已验收的登录方案。

- R01：目标双域名与纯 IP HTTPS 双端口，实际 CA 根信任、IP/DNS SAN、反代、Host/端口、静态深链、未知入口拒绝与跨应用 Cookie 隔离（A02/A23）。
- R02：至少一次真实一小时/隔天停留及机器休眠恢复，不能以虚拟时钟替代（A03）。
- R03：真实 Auth/IAM 的资格撤销、锁定/禁用、重置/强制改密、安全踢出、另一浏览器重放及网络/依赖故障；模拟/隔离证据不可冒充实际演练（A05–A09/A11–A21中尚无实际证据部分）。
- R04：维护窗口协同切换、旧 Cookie/Redis盘点与定界清理、监控/补偿、完整版本回滚和回滚后的验证（A24）。
- R05：记录目标环境与版本、执行者、日期、脱敏结果和失败处置；不能只打全选勾。

不包含新增认证功能、外部 OAuth2/SSO、四域兼容或无授权的生产操作。
