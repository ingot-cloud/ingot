## 性能复测

2026-11-09 使用 [基线](./BASELINE.md) 的合成身份、请求路径、数据规模和 SQL 计数口径，在隔离 MySQL 8.4 与 Redis 8.2.0 上复测。每组串行预热 30 次、采样 200 次，15 个场景共 3,000 次成功请求。直接查库、冷读和热读分别测量。直接查库是首轮夹具的对照组。冷读在计时前清除本应用的共享代次，计时覆盖缺失后的装载与回填。热读在已预热的代次上采样。
