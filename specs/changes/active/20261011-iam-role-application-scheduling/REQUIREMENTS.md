# 需求与验收

来源：用户确认各节点低频兜底后要求执行最终调度优化计划。

空闲数据库扫描默认每节点60秒一次；确认事务提交后本节点立即唤醒，异步广播其他节点。工作线程按任务ID执行最多100条分配的事务批次，剩余项250毫秒后重新排队，多个任务交替执行。通知只保存提示，不承载身份、范围或授权；丢失时数据库任务和低频扫描保障接续。

保留30秒数据库租约、同角色唯一RUNNING、锁顺序、fresh门禁、暂停/显式继续和事务审计。单节点同一任务无并行执行，多节点竞争不重复写入。数据库健康、队列无积压时，本节点确认后目标1秒内开始领取；故障接续发现默认等待最多约90秒。

有界去重队列，容量溢出只丢提示，不丢持久任务；禁用通知、Redis故障、重启和关闭领取均有明确定义。数据库异常扫描60/120/240/300秒退避。指标不追加轮询SQL，空扫描不产生日志噪音。

自动化覆盖虚拟时间、去重、错峰、退避、通知提交边界、队列溢出恢复、多节点竞争/接管、撤权及审计。人工验收两节点空闲至少10分钟，确认实际频率及故障恢复。无需SQL迁移、前端变更、目标库执行或Git提交。
