# 验收与回退设计

确认目标环境、账号、版本、数据库和操作窗口后采集。会话通过实际登录链路建立，按入口现行规则完成验证码。性能对照沿用已归档方案的测量口径，记录采样时间、次数、数据规模、连接池和冷热状态。缓存指标按实际接入情况记录。

已有库使用 [037 在线索引迁移](../../../../databases/iam/migrations/037_tenant_assignment_list_index.sql)。在经批准的发布窗口先加索引，再切换兼容后端，最后切换管理端摘要视图。回退按管理端、后端、索引的顺序执行，保留分配数据。新建库使用当前初始化包。

记录实际生效版本后，在 IAM 用户组、读取性能、租户即时授权、数据库持久化及管理端用户组和错误处理能力中同步运行基线。保留已归档的本地验收原始结果。
