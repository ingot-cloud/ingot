# Requirements

用户于 2026-10-19 明确“开始实施”，批准前一轮完整 Plan 和已选择决策。

1. 部门负责人独立组织关系，不授予角色/操作/数据范围/字段特权，不写 Token，不改变通讯录策略。
2. 仅普通部门；零或多名负责人，非空必须有且仅有一位主负责人；允许本租户有效成员跨部门兼管，不改变任职部门。
3. 独立设置负责人 ACTION，继续使用现有角色和对象范围；候选沿用成员读取范围。
4. 暂停/移出保留关系并显示不可用；暂停恢复后有效，不自动继任；不阻断安全停用与移出。
5. 首版部门列表及详情维护；不增加通讯录标签、岗位、审批、动态角色范围、批量导入导出或新建部门同步任命。
6. 保留现有真实部门树、根部门组织总人数、直属成员统计、成员入职和已有角色行为。关系非空拒绝删部门，含负责人部门不能改为根。

## 2026-10-19 交互调整（用户已批准）

部门详情取消 Tab，负责人和基本信息使用同一编辑会话及一次原子保存。按实际变化分别校验部门编辑/负责人维护权限；只有其中一种权限也能编辑对应字段。负责人身份不授予权限、范围或 Token 属性。

租户端选择人员统一为可聚焦录入框 → 组织成员对话框 → 确认回填草稿 → 业务保存。部门只导航不可选择；支持逐层展开、面包屑、当前组织全局搜索、跨部门/跨页保留、成员ID去重。多选双栏、单选单栏。主负责人只作为部门业务扩展。

现有租户成员录入入口（负责人、用户组、应用人群、成员策略、角色分配/委派、诊断、所有者转交）迁移到公共组织选择器。平台成员选择和部门/用户组等非人员对象选择维持原语义。候选来源沿各场景原有接口及准入，不补成员管理权。没有部门读取权时只显示组织根候选，不扩权展示部门。


## 2026-10-19 飞书对照精修（用户本轮明确批准）

以用户提供截图及飞书实页核对成员对话框：宽840px、多选等宽双栏、内容高420px、正文14px/22px、行高48px、头像32px、栏内间距16px；外层24px边距，底部按钮80px，窄屏收缩。使用框架主题的文字/边框/悬停/主题背景与主色，不写死飞书蓝。

- 搜索下方展示组织名称和当前部门面包屑，用右箭头分隔，末级仅文本，祖先可返回。组织名称仅在当前部门读取范围可见时返回，否则“当前组织”；禁止借完整树补隐藏祖先。
- 勾选文案“全选”，仍只作用于当前加载页的可选人员，不选择部门、不隐式拉全量。部门用32px组织图标圆底，成员用32px头像/姓名占位，候选与已选复用一致图像；行可点击、键盘可操作、悬停有反馈。
- 右栏有选择后显示“已选：N 名用户”和“清空”，姓名下方显示该成员实际任职部门（可多部门），来自候选/绑定页的受限投影；选择和切换主负责人时不另行查询成员详情。为空时留白。
- 部门负责人扩展：标题“请选择”；有多个负责人时顶部提示“可选择多位部门负责人，必须有一个主负责人”；首位从空集合新增的有效成员自动成为主负责人，其他人可用“设为部门主负责人”切换，“部门主负责人”为主题浅底标签。用户在草稿中移除当前主负责人时，优先将首位已知且可用的剩余成员设主；没有可操作剩余成员则要求继续加载/明确选择。既有受限或不可用主负责人不能仅因打开对话框而自动更换，账号状态变化也不自动继任。
- 搜索文案仅声明已实现的姓名检索，不虚示邮箱/手机号/ID检索。默认授权、数据范围、字段策略与Token契约保持不变；自动设主仅是负责人表单草稿默认值，确认后仍等待外层保存及后端重验。
- 负责人候选/绑定返回departments最小任职投影；当前角色分配成员候选可返回同样的部门信息，须同时满足既有成员与部门读取范围，不能扩大原候选池或为复用而补权。导航增加可选organization名称对象；旧字段和路径保留，无数据库迁移。

## 选择器根部门与勾选修正（2026-10-19，用户已授权）

根节点仅包含显式绑定根部门或没有任何部门关系的成员。绑定普通部门后不再自动出现在根；显式根与普通部门双绑定均显示。仅绑定不可见部门不能当作未分配。此规则只用于组织成员选择器，搜索仍跨场景候选池。勾号与半选标识按当前 Element Plus 的居中机制显示。

本轮验收：外部空/完整/部分已选快照不重查首屏；21+条候选/部门/已选可操作追加，零条、不足20、恰好20及末页均无加载更多；按钮居中、间距一致，浅深主题及小视口可用。验证取消、设主、分页去重、失败重试、搜索/分支/身份变化、未加载关联保留。

## 部门详情聚合与上级单选（用户授权）

部门详情无Tab，顶部显示56px主题圆底部门图标与部门名称；负责人确实未设置时显示ASCII `-`，不可见/受限不得伪装为空。详情及统一编辑响应一次返回展示和进入编辑所需的可见上级部门名称、负责人第一页及元数据；打开抽屉不再追加负责人首屏查询，不拉全量负责人。上级部门展示名称，隐藏时显示受限而非裸ID。编辑采用成员页同一部门树对话框的单选模式，确认后回填、取消不变；当前部门及子树不可选，服务端仍重验租户、范围与循环。成员多选、主部门排序及原保存规则保持兼容。
