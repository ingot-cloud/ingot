## 最小测试数据

两个组织 A/B；一个同时有平台及两租户身份的账号；各一个拥有者、普通成员、仅委派管理员；根/研发/子部门及多部门/无部门成员；共享角色多旧版本、独立私有角色、旧差异角色；直接、组、委派分配，未来/到期/撤销来源；一个同资源多操作异范围的旧委派；有效、待生效、到期、停用和未开通应用；任意已注册租户资源和字段能力；平台固定版本与历史/运行任务。

自动化使用隔离 H2/MySQL/HTTP fixture，真实兼容验收仍需 MySQL 和一致部署。不得连接实际库重建来代替隔离测试。性能规模按 DESIGN 建立，fixture 的示例 ID 不作正式初始化。

## 退出条件

- 所有 B 项及前端矩阵有证据，单元/Mock、真实HTTP、浏览器和性能证据区分。

- 用户确认产品验收后，方可更新 current 与归档；未完成项拆为新的 active change，不悄悄删任务。
