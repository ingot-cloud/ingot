# 需求与验收

- 2026-10-30 导航验收修正：租户工作台位于一级导航最上方，其他菜单相对顺序不变。排序保存于服务端菜单配置，新初始化与已有开发库保持一致。

1. 页面仅包含组织统计、快捷入口、我的待办。首行统计跨三列、待办占一列，下方快捷入口横向多列；窄屏重排，不继承飞书最小宽度限制。
2. 使用现有 Overview 原型、InPageHeader、InIcon 与语义 Token。参考实测：网格间距 12px、卡片内边距 20px、圆角 12px、标题 16/24px、正文 14/22px；入口高至少 64px，底座 40px、图标 20px、图文间距 12px。悬浮和键盘焦点轻阴影/上移，遵守减少动效。
3. 四个真实统计：在册成员、部门、用户组、可用应用。无读取权限显示“—”，零正常显示 0；加载有反馈，失败有重试，不继续展示过时成功数。
4. 快捷入口来自当前用户可见菜单，保留顺序、标题、icon、路径、所属分组。排除工作台自身、目录、重复路径；菜单变化时同步更新。缺 icon 只用统一占位，无业务路径到图标映射。
5. 我的待办显示“暂未接入业务待办”，不请求接口、不展示虚构任务或假计数、不提供无真实目标的筛选/查看全部操作。
6. 切换身份、租户或授权上下文后，统计不得沿用旧上下文；所有 COUNT 应绑定可信组织与已有读取范围。暂停计入成员、移出排除、部门根不计入、应用按可见入口去重。
7. 后端权限隔离/范围/计数测试通过，前端动态图标/入口排除与统计状态测试通过，类型检查与构建完成；浏览器核对真实接口、明暗主题、窄屏和快捷入口跳转。
