## 需求和边界

- 平台审计仅含平台治理操作；平台治理组织的记录仍归平台域。租户审计仅含当前可信租户的操作。
- 同账号的不同身份不合并权限与审计，不新增跨租户读取能力、安全事件查询或导出。
- 页面及正式菜单统一称“授权审计”，显示平台/当前组织上下文，移除管理域切换。
- 无审计读权限不发请求，显示无权限；授权不可用、请求失败与合法空结果分别展示。
- 表格展示时间、操作者、变更类型、目标及安全摘要；详情展示安全差异、版本、关联分配/委派及追踪信息。操作者名称继续受成员读取和字段规则约束。

## 接口和实现决策

两条 GET `/v1/{platform|tenant}/authorization/audits` 保留分页及响应结构，新增可选参数：

| 参数 | 规则 |
|---|---|
| actorMemberId | 当前域成员 ID 精确匹配；正数十进制 ID，不按姓名搜索，避免推断隐藏姓名 |
| targetType | 资源类型精确匹配，去首尾空白，最长 64 字符；开放资源编码 |
| targetId | 目标 ID 精确匹配，去首尾空白，最长 128 字符 |
| changeType | 既有 AuditChangeType 枚举；未知值 400 |
| from | 起点包含，带时区 ISO-8601 时间点 |
| until | 终点不包含，带时区 ISO-8601 时间点；两端存在时必须晚于 from |

HTTP 边界解析并校验参数；查询服务在访问审计数据前执行身份与 ACTION 准入，域/租户条件由服务端恢复。所有筛选在 SQL 分页和 COUNT 前应用，保持 occurred_at DESC、id DESC。时间解析复用框架严格转换，数据库比较转 UTC LocalDateTime。前端主搜索为操作者成员 ID，其余条件在 InFilterPanel，日期控件通过 toApiInstant 转 UTC。

审计写入集中将白名单差异值标准化为字符串：字符串原样保留，标量转文本，数组/对象转紧凑 JSON 文本，null 保留；读取兼容已有数组/对象，仅返回 AuditField 白名单。公共 AuditEntry 的字符串值契约不改。格式损坏/内部序列化失败使用既有 S0500/HTTP500，记录审计 ID、列名和当前 trace，不输出原始 JSON；不跳过或删除真实审计。

详情直接消费已有分页记录，不新增详情查询；目标仅展示资源及 ID，不额外读取业务原值。行键使用审计 ID。菜单保持路径/viewPath/权限不变，仅名称调整；正式种子修正并提供既有库幂等菜单名称迁移脚本。

## 兼容、发布和回退

旧请求无筛选时行为不变；响应、权限码、审计表不变。已有审计无需数据迁移。先发布后端再前端，菜单名称脚本可独立执行。回退保留审计事实；新记录仍可被旧字符串读法读取，旧数组记录在旧后端中仍有原故障。名称可按旧菜单名回退，无身份/授权变更。
