# 前端页面与交互规格

> 本文件是后续前端 Agent 的输入；本仓库不实现页面。与 API、DESIGN 一并读取，遵守前端仓库自身 SDD 及架构规范。参考已观察的飞书分步配置、部门选择、只读详情和预览方式，不声称复刻飞书内部算法或商业版本限制。

## 1. 导航与架构

同一管理台明确显示平台/当前组织身份；切换重新建立认证上下文，清除旧菜单、资料、查询缓存和请求，忽略迟到响应。

平台最多四个一级目录：

| 一级 | 二级及 Tab |
|---|---|
| 组织与租户 | 租户管理；详情 Tab：基础信息、应用开通、所有者、状态记录 |
| 应用与配置 | 应用目录、套餐、共享角色、字典；应用详情 Tab：基本信息、资源与操作、菜单 |
| 平台管理 | 平台人员、角色与授权；后者 Tab：角色、授权记录、授权管理员 |
| 安全与运维 | 现有安全策略、会话、事件与审计、运维能力；不新增未经后端支持的空功能 |

租户最多四个一级目录：

| 一级 | 二级及 Tab |
|---|---|
| 组织管理 | 成员与部门、用户组、组织设置 |
| 权限与应用 | 角色与授权（角色/授权记录/授权管理员 Tab）、应用管理 |
| 安全与合规 | 成员权限（通讯录可见范围/字段权限 Tab）、现有安全设置、审计 |
| 工作台 | 已授权业务应用入口、普通通讯录 |

诊断在角色与授权页工具入口及成员详情快捷入口，不独立一级菜单。资源、操作、范围、版本均放详情。无可见子页时隐藏父目录；跨页链接亦验证目标能力。

沿用 Vue 3、Element Plus、现有详情抽屉、主题 Token。业务页面放相应 plugin，通用选择器、范围编辑、权限展示进入公共包，插件不互相依赖。导航不按微服务或数据库表划分。

## 2. 页面交互

### F01 租户管理

列表按状态及名称筛选。创建使用全页向导：组织资料 → 指定所有者 → 基础应用/套餐 → 预览并提交。展示将创建的最小实体及开通结果，不出现“复制角色模板”选项。不向管理员泄露账号是否属于其他组织。

详情默认只读。应用开通修改显式展示开始/结束、来源、禁用及过期结果；套餐变化不自动应用。停用展示影响并确认；平台页面无“进入租户业务”入口。

### F02 应用与配置

资源和操作在应用详情内联合展示。操作区分查看、编辑、导出、移出等，不用“管理”复选项包办全部。范围候选从资源能力接口读取。菜单配置独立引用进入页面 ACTION，可选择 ANY/ALL，不创建按钮菜单。

字典及现有安全页面沿用各自领域功能，只更新身份及授权接入。未实现的能力不以空按钮占位。

### F03 成员与部门

左侧部门树、右侧成员表。姓名/头像打开只读详情，基本资料、部门关系、授权信息分区。拥有相应操作才出现编辑、调部门、暂停、恢复、移出、导出。

只读角色看到正常描述内容，不用 disabled 输入框冒充详情。编辑时隐藏或脱敏字段不进入表单。保存仅提交修改且可编辑字段；授权变更不能使旧表单提交受限字段。

多部门成员显示可见部门关系；无权操作的对象按钮按后端 capabilities 禁用并显示原因，不自行用部门数组判断权限。组织移出明确说明不删除全局账号。非空部门删除与子树移动由服务端返回具体限制。

### F04 用户组

列表展示名称、有效人数（有权范围内）和用途。详情 Tab：成员来源、有效成员、引用位置。成员来源可以直接选人或选部门，部门旁有“包含下级”开关；有效成员去重显示来源。

修改前调用 preview，列出受影响角色授权、应用和策略；越权阻止提交。删除被引用组说明引用位置，不静默级联撤权。无权知道具体引用时只显示受限摘要。

### F05 角色目录与编辑

目录筛选系统治理、平台共享、租户定制、自定义；显示当前版本、使用版本和状态。共享只读，操作为“分配使用”“基于此角色定制”。系统治理无定制按钮。

创建/定制全页步骤：
1. 基本信息：名称、说明、分组、基础共享版本（若定制）。
2. 功能选择：应用 → 资源 → 具体操作；提供“仅选查看”和当前项全选。
3. 范围：只展示选中操作；显示“本人所属部门”和“授权时指定管理部门”区别；包含下级独立开关；支持复用命名参数。
4. 预览：自然语言展示最终能力、参数、版本及影响，完整校验后发布。

定制有“最终生效内容”“本组织调整”两种视图，标签为“来自平台”“本组织新增”“本组织移除”“范围已调整”。恢复平台设置删除差异。移除文案说明仅本角色不授予，不宣称此人全局禁止。

无依赖隐含勾选。编辑无查看时提示可能无法进入页面，允许管理员明确选择是否补充查看。新版本发布不自动升级授权；详情允许追踪旧版本。

### F06 共享版本升级

选择新基础版本 → 三方差异 → 解决冲突 → 预览最终定义 → 选择升级授权记录 → 提交。默认不选择既有授权。未处理冲突禁用提交；操作删除/范围改变不静默取新旧其中一个。展示不兼容的委派来源，须先更新其允许版本后再升级派生授权。

保存出现 409 保留解决草稿并重新比较，不直接覆盖。后台不能通过发布共享版本即时扩展所有租户权限。

### F07 授权分配

大抽屉步骤：人员/用户组 → 角色版本 → 范围参数与有效期 → 效果预览。受限管理员只列可分配版本，候选人员和管理对象也受其委派限制。

所属部门按每个接收者展开预览；指定管理部门不随接收者任职变化，旁边解释。多个操作复用参数显示引用清单。不可用应用的角色项标记原因，不提交无效授权。

列表显示直接/组来源、角色版本、范围摘要、期限、委派来源。撤销有影响确认。批量提交中任一项无效均不保存，逐项展示错误。

### F08 授权管理员

配置管理员、角色版本白名单、接收对象、逐操作范围上限和期限。明确“允许给别人授权，不自动获得业务操作权”。无二次委派或角色创建开关。

收缩/撤销先展示派生授权影响。与角色发布无隐式联动，新角色版本必须显式加入白名单。此页自身由治理权限控制。

### F09 应用可用范围

只配置平台已开通应用的人群和租户开关，显示平台开通期限。说明“应用可用不等于拥有其中的业务操作”。所有者治理基础入口不可被普通配置关闭。

### F10 通讯录与字段

通讯录先默认规则，再允许/禁止规则。句式：“哪些成员，可以/不可以，看到哪些部门或成员”。选择预览成员后显示真实可见树与成员样例、匹配原因，必要路径用导航骨架样式，不显示隐藏分支统计。

字段页先选场景、查看者、目标范围，再字段矩阵：隐藏/脱敏/完整、可编辑。非完整不能开启编辑；完整也不自动授予更新操作。右侧样例使用服务端预览的脱敏数据。多规则严格取值及平台上限明确解释。

### F11 权限诊断与审计

诊断输入成员、应用、操作、可选目标。输出结论、应用状态、直接/组授权、角色版本、委派、范围与字段限制。提供有权配置的跳转，不提供“模拟执行”或登录按钮。

审计按操作者、对象、类型、时间筛选，详情展示安全前后差异和来源链。导出为独立操作，不能含凭证或被隐藏的字段原值。

### F12 普通通讯录与工作台

与后台成员管理调用不同 API。只有通讯录权限也可浏览，但没有后台编辑入口。搜索、人数、列表和详情均消费服务端结果。业务应用入口同时受开通、人群和页面操作约束。

## 3. 通用交互与状态

| 状态 | 页面行为 |
|---|---|
| 无 ACTION | 隐藏菜单/操作，不加载无权详情 |
| 有 ACTION 但对象越界 | 对正常可见对象禁用操作，展示后端 reason，不暴露隐藏目标 |
| 业务状态不允许 | 展示业务原因，例如部门非空 |
| 提交中 | 防重复提交；批量事务失败不误提示部分成功 |
| 未保存离开 | 关闭、Esc、切 Tab/路由提醒丢弃；取消留在原处 |
| 409 | 保留草稿，刷新差异后重试 |
| 撤权/403 | 刷新能力与菜单，关闭不可见详情；保留本地输入供查看/复制但禁用提交 |
| 503 | 重试状态、阻止受保护操作；不当成成功空列表、不登出、不把旧数据视为最新 |
| 404 | “不存在或不可访问”，不区分真实存在 |
| 空范围 | 已确认有功能且查询成功时显示“当前范围内暂无数据” |
| 切换身份 | 清缓存、详情和路由，忽略旧响应，重新 bootstrap |

角色名不能用于前端放行。使用响应式能力，不只在 mounted 时移除 DOM。对象能力随列表批量返回，无每行一次权限查询。授权到期后使用前刷新，403、窗口重获焦点及身份切换触发更新；前端永远不是最终安全边界。

## 4. 前端交付与联调

前端 Agent 应在其仓库创建关联 change，保持四个一级目录及以上业务语义。API 未实现时可按本契约创建测试夹具，但不能自行决定权限合并或迁移策略。

实现前校对后端已验证 OpenAPI；每个页面需覆盖只读、范围受限、字段限制、编辑离开、冲突、撤权、503 和跨组织切换。验收编号见 ACCEPTANCE 的 F 系列。前端任务不在本仓库标记为已实施。
