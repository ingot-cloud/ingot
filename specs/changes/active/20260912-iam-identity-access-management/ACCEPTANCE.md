# 验收矩阵

所有用例必须有明确身份、组织、资源操作、输入及预期。禁止只以超级管理员跑通页面作为权限验收。当前均未执行。

## 后端

| 编号 | 场景 | 预期 |
|---|---|---|
| A01 | 平台管理租户后请求其成员资料；租户 A 请求 B 对象 | 拒绝跨域/跨租户，平台治理不绕过 |
| A02 | 所有者刚开通业务应用，再显式自授权 | 授权前无业务操作，授权后生效且有审计 |
| A03 | 连续创建多个组织 | 无平台角色/资源/菜单/权限条目复制，无空差异；只增加必要事实与引用 |
| A04 | 直接分配共享角色、定制 ADD/REMOVE/REPLACE_SCOPE、恢复基础 | 存储最小差异、合成正确、移除不影响其他角色授权 |
| A05 | 平台发布新版本、三方冲突、只升级选中授权 | 旧引用不变化，冲突未解决不提交，新委派版本不自动跟随 |
| A06 | 研发查看员：成员列表/详情/搜索及手工写/导出 API | 仅研发及下级，手机脱敏；创建编辑移出导出拒绝 |
| A07 | A 研发编辑+B 全组织查看，另有孤立旧编辑 ALL 规则 | 只能编辑研发，孤立范围不参与 |
| A08 | 所属部门/指定部门授权后调整任职 | 前者变化，后者不变；无部门不命中部门范围 |
| A09 | 多部门成员暂停/移出、部门移动及非空删除 | 全关系覆盖/子树与目标校验，非空拒绝 |
| A10 | 原/新归属、并发变更、同步批量写、异步导出下载 | 两端校验，无部分静默成功，无任务/文件绕过 |
| A11 | 受限委派超角色/人群/范围/期限；拼接两委派 | 全部拒绝；业务操作权不自动转为委派权 |
| A12 | 撤销/收窄委派，组扩大、部门变化、角色升级 | 派生授权持续受限，改组不能间接扩权 |
| A13 | 默认/允许/禁止通讯录组合和本人例外 | 列表树搜索详情选择器计数一致，祖先不泄露隐藏分支 |
| A14 | 多字段策略、平台上限、修改受限字段、导出/检索 | 严格取值，原值不出响应，编辑与原值查询被拒绝 |
| A15 | 到期、禁用应用/角色、成员退出、广播失败、远端故障 | 有效期最长 30 秒且到期精确截断；503 不成功空返回、不延长旧授权 |
| A16 | 预览后配置变化再提交；授权同时被撤销 | 409/授权拒绝，预览不作放行凭证，无混合版本快照 |
| A17 | 诊断与审计用户不具目标详情权限 | 不暴露原值或越界对象，不执行操作/模拟登录 |
| A18 | 服务改名、RPC、Gateway、Nacos、镜像启动 | 运行链路无旧 PMS 依赖，Auth/Security/辅助功能集成通过 |
| A19 | 非超管覆盖全部资源入口/缺操作初始化 | 每 API 对应合法 ACTION 及执行器，无漏接表/旧角色短路 |
| A20 | 多角色多组大部门分页及 count | 批量规则加载，无权限×角色 N+1、无内存分页；检查索引执行计划 |

## 迁移

| 编号 | 场景 | 预期 |
|---|---|---|
| M01 | 同批次重复导入，源快照变化 | 无重复成员/授权，变化源不能复用旧已验证批次 |
| M02 | 账号、多组织、删除/停用、密码历史/锁定 | 身份可追踪，状态保留，组织移出不删除账号 |
| M03 | 通配、缺操作/范围、超管、所有者歧义 | 明确映射；其余阻塞清单，不自动 ALL 或全部变所有者 |
| M04 | 默认开放、显式禁用、未来/过期应用 | 正确转为显式开通和期限，不复活被禁用应用 |
| M05 | 共享角色和已有租户追加 | 固定基础+最小差异，无整套副本，权限变更分类可追踪 |
| M06 | 字典/套餐/发号/社会化/审计/未知表 | 逐表有去向，密钥依赖验证，ID 不碰撞，发号不倒退 |
| M07 | 源库写保护、停写导入、失败与回滚窗口 | 源库未修改，失败未 verified，开放新写后不得直接回旧库 |
| M08 | 差异报告中扩大或无法证明等价的授权 | 需明确处置，不以抽样替代范围证明，无未确认扩权 |
| M09 | 导出日志与报告、会话及缓存 | 不含凭证/敏感原值，不迁旧会话/授权缓存，重新登录 |

## 后续前端联调

| 编号 | 场景 | 预期 |
|---|---|---|
| F01 | 平台/租户菜单及无权目录 | 各最多四个一级目录，诊断/资源/版本不另增一级 |
| F02 | 创建组织、共享直接分配、定制及恢复 | 无复制步骤；来源标签、最终/差异视图正确 |
| F03 | 角色向导、分配、多接收人范围及升级冲突 | 参数明确，预览实际结果，冲突/超限禁止原子提交 |
| F04 | 成员只读、对象范围、字段编辑、导出 | 只读描述正常，无无权操作，脱敏值不提交 |
| F05 | 编辑离开、409、403撤权、503、切换身份迟到响应 | 保留草稿且不越权提交，错误正确分流，无旧域数据混入 |
| F06 | 通讯录/字段预览、组影响、诊断 | 真实引擎结果及受限来源，无模拟执行 |
| F07 | 表格能力刷新 | 响应式更新，无每行权限请求，无角色名放行 |

## 证据与门禁

单元测试覆盖规则组合和合成；真实数据库测试覆盖 SQL、事务、范围和迁移；契约测试覆盖 JSON/错误/OpenAPI。前端组件及 E2E 在其仓库执行，证据引用回联调记录。

后端代码与工具可先验收，但正式切流必须完成 M 系列及 F 系列。不得在前端尚未实施时勾选 F 系列，不得在没有真实快照演练时宣称迁移已完成。
