# 平台角色工作区与委派优化（2026-10-03）

状态：approved；用户已明确批准实施，实施期间主 change 保持 implementing。

## 已批准决策

- 角色 Tab 使用左侧角色分页搜索、右侧成员/用户组工作区；成员按有效直接分配及可披露的组继承去重，默认所有固定版本，支持版本筛选；历史保留在角色分配 Tab。角色读取与分配读取独立，继承遵守组成员查询范围。成员行查看来源，来源行才调整/撤销，禁止用移出组代替撤权。
- 新增角色关联分页 GET /v1/platform/roles/{id}/members、/groups、/members/{memberId}/assignments。查询/计数同边界，不拉全集或逐成员查询。
- DelegationInput.assignmentDurationMode=LIMITED|UNLIMITED，省略兼容 LIMITED。有限模式要求正的 maxAssignmentDuration 及派生截止时间；不限模式不提交时长，允许长期分配，实际截止受来源委派限制。租户不开放不限模式。模式收窄全面预览冲突，事务重验。
- 禁止平台管理员通过本人的委派自我授权，包含有本人的组；新旧统一生效，历史保留并显示来源失效，其他合法分配不受影响。候选 excludeMemberId 仅改善交互，提交及运行期独立校验，组变化失效缓存。
- 委派多角色版本、多成员保持；label 简化，时间模式默认 LIMITED/30 天，四步左侧导航保持。支持 ALL 的新增操作显式默认 ALL，不支持则待配置；编辑不重置，ALL 与其他范围互斥。同资源批量设置与对象复制覆盖先提示；所有草稿改动废弃预览。
- 权限展示使用 --in-permission-panel-bg（浅色 #f8f9fa，深色主题柔和背景），角色详情/确认操作/预览一致；间距与字段对齐统一。实体与树加载使用 InLoading。
- 候选页与已选集合独立，草稿存名称/版本/层级；同上下文打开通常只请求候选第一页。对象第一页同时判断 hierarchical 并直接复用，不独立探树、不强制重复 ids 回显。首编辑缺信息才回显，大量关系使用 GET /v1/platform/delegations/{id}/selected-candidates（kind=MEMBER|ROLE_REVISION|OBJECT，OBJECT 带 actionId）关联分页。分页不将未出现判失效；上下文变更、迟到响应、失败及未知适配器按现有 fail-closed 规则处理。
- 扩展现有 in-coding-standards reference，不新建 skill、不改 AGENTS.md。
