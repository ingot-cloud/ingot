## 目标

租户字段策略按资源接入。平台资源决定能否配置以及能配哪些字段，生效时只在角色字段上限内收紧。成员仍是唯一接入的资源，默认脱敏不变。

## 范围

包含：

- 资源描述增加字段策略运行能力，目录增加接入开关
- 字段策略、字段规则和默认修订按资源存储，去掉场景维度
- 已接入资源走「策略收紧后再与角色并集取更严」，未接入资源只读角色快照
- 策略接口按资源列出、读取和保存

不包含：

- 第二套业务资源的字段或目标范围
- 非成员记录的目标范围类型
- 角色对象范围表达的数据隔离
- 归档通讯录移除变更，或提前改写 `specs/current`
