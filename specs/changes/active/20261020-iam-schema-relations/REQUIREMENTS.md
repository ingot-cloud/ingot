# Requirements

1. manifest 中所有表和字段具有准确中文说明，生成列明确约束用途；保留已有有效信息。
2. 权威 DDL 生成数据字典及完整初始化文件；框架表在框架源维护。
3. 提供可重跑的注释升级及只读结构核对，结构不匹配时在任何 ALTER 前停止；仅修改 COMMENT，保留全部结构和数据。
4. 成员部门复用同一写入实现；组、菜单操作、套餐应用按差量维护；负责人主标记未变化时不写。
5. 保留完整集合、空值、重复输入、租户隔离、权限、锁、版本、审计、缓存失效及事务回滚契约。
6. 全表评估记录主键/索引/外键、入口、键宽、发号方式、重写情况、结论、优先级和验证依据；不凭静态代码宣称真实页碎片。
7. 人群、开通重置、委派与快照只审查；不改变公共 API、字段名及主键。

## 验收

- [x] 所有表字段有注释，生成工件无漂移。
- [x] 注释升级前后除 COMMENT 外定义及数据一致，可重跑，漂移预检不产生任何 ALTER。
- [x] 不变关系零 DML，保留行不重插，标记/属性变化只更新对应行。
- [x] 隔离 MySQL 验证唯一主关系及并发版本冲突；Java 验证权限、版本、回滚与 SQL 计数。
- [x] 报告覆盖全部 manifest 表，并列明后续候选及运行数据需求。
