# 需求

在实际目标环境保留既有 IAM 数据，将租户授权切换为已验收的当前权限模型。沿用原迁移手册的 M01–M05 转换与 P01–P10 放行门禁。

- R01 登记目标环境、来源库、发布窗口、负责人、部署制品和授权范围。实际来源只读预检必须有明确结果；发现范围冲突、指纹漂移或不明引用时停止放行。
- R02 保留完整备份，并提供可还原验证。隔离样本演练与目标环境备份恢复分别登记。
- R03 核对结构与转换结果后联合部署 IAM、消费 SDK 服务和两个管理台。验证拥有者、角色生效、权限撤销、字段限制和平台固定版本回归，再开放写入。
- R04 保留观察窗口内完整备份回滚及放开新写入后逆转换的可执行证据。记录环境、版本、日期、执行人、结果和异常处置。

范围限发布与验收，业务模型、接口和迁移脚本沿用已验收制品。
