# 需求与验收

用户在 Plan 阶段确认完整方案，并于 2026-10-12 明确要求实施。

- 字典属于平台治理的系统设置；安全中心独立为 PLATFORM / platform:security。
- 保留现有接口、精确操作码、数据作用域和不可变角色版本；不自动扩权。
- 移动八个页面并直接切换新 URL / canonical viewPath，不提供旧入口。
- 成员访问策略迁入 org，两域审计以各域包装页消费 admin-common 无路由组件。
- 安全六资源十六操作仅 ALL，通过授权 SDK 执行；前端精确能力判断和活动 Tab 请求门禁。
- 新库正式种子及已有库幂等补丁，保留目录 ID / 版本 / 分配 / 委派 / 审计引用；冲突整笔回滚。
- 不增加通用安全事件查询，不连接实际数据库，不提交 Git。

验收：生成一致性、隔离 MySQL 新库/升级/重跑/冲突回滚、后端授权正常与拒绝链路、前端权限与 Tab 测试、类型检查、只读 lint、依赖边界、两管理台构建。人工确认深链接、搜索、应用切换、窄屏和主题后更新 current 并归档。
