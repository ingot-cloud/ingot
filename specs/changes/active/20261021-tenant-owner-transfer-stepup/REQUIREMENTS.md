# 需求：所有者转交内嵌登录密码

## 场景

当前所有者转交组织所有权。请求必须同时带新成员和登录密码。密码错误或未带确认时，所有者不变。

## 验收标准

- 转交权限通过后，先确认调用者是当前所有者，再验密码，然后才锁行转交。
- 缺 `confirmation`、口令为空、种类不是 `LOGIN_PASSWORD`、口令错误，均为 `STEP_UP_FAILED`，不写库、不失效缓存。
- 新所有者就是当前所有者时，也必须先验密码；密码通过后才允许保持原状返回。
- 非所有者即使带了正确密码，也是 `ACTION_DENIED`，且不把验密结果当成转交成功。
- 不新增独立验密 HTTP。
